# outpost2 — 前哨 2.0

> 一台「学会了且想继续学就毕业」的全托管学习机。
> 产品宪法与架构：[docs/CONSTITUTION.md](docs/CONSTITUTION.md)（2026-10-14 定稿）。

## 定位

用户的界面只剩两个动作：**完成今天丢来的内容**、**看自己的履历**。
调度、知识来源、出题、造坑、验收，全部由系统承担；AI 助教只做脚手架不做代工（P29 四纪律）。

## 五层架构

| 层 | 职责 | 状态 |
|---|---|---|
| 调度层 | 「今天丢什么」：产出物×FSRS×精力 → 今日计划（含可选加餐）+ bandit 计划形态学习 | ✅ v1.5（internal/scheduler + internal/bandit） |
| 履历层 | 知识点 × 深度（知道/用过/做过）× 时间 × 来源 + 证据页导出 | ✅ v1（internal/evidence） |
| 能力评估 | Elo per 域：难度带 50-90% 校准，AI 助教评估能力的数字底座 | ✅ v0（internal/ability） |
| 知识库层 | 三层：原文锚定（授权白名单）/ 助教理解（无原书指纹+相似度闸门）/ 批判批注（冲突检测） | 规划中 |
| 练习层 | break-fix 沙盒：AI 预埋教学 bug → 修复=确定性验收；精准喂坑 | 规划中 |
| AI 助教层 | 护栏四纪律（已在 1.x P29 落地）+ 记忆结晶 + 品味进化（学会了且想继续学三信号） | 部分（护栏在 1.x） |
