# 怎么用它学（使用指南）

> 写给完全新手。照着做就行，不用理解背后的机制。
> 一句话：**每天打开它，做今天那四步；今天过不去的，明天接着做。**

---

## 一、每天打开，看到四步

```
01 学    助教一对一讲一个知识点
02 练    做几道练习题（只考今天讲过的）
03 复习  到期该重看的旧知识点
04 副本  一个真项目：做完才算学完
```

**顺序别跳**。每步不到「过」就别往下走——
不是纪律要求，是往下走也没用（下一步会用上一步的东西）。

---

## 二、第一步「学」：一节课怎么走

助教会按这个顺序来，你只需要跟着做：

1. **他先问你两个小问题**（探底）
   → 会就答会，不会就说不会。**这一句决定了后面讲多深，别装懂。**
2. **他给全貌**：这段东西是干什么的，分几块，你要动哪块
3. **他给完整代码**，逐块解释，并给一条能**复制粘贴就跑**的命令
   → 你照着跑一遍，看到他说该看到的东西
4. **他让你改一处**（半做）
   → 只改一处。改完再跑，看到该看到的变化
5. **他让你独立做一个小的**（关掉范例）
   → 卡超过 10 分钟，可以看对应那一块，然后**重新独立做完**
6. **空白重写关**：合上讲义，不看对话，把这个东西自己写一遍/口述一遍
   → **这一关不过，这节课就不算过**
7. **必须掌握清单**：3~6 条，他会问你这几条会不会
8. **两道实际场景题**：给你一个情境问「你会怎么做、为什么」
   → 他必须判你的回答；答不上来他会给最小提示，再答一次

### 卡住的时候怎么说

说清三样：**我在做啥 / 我试过啥 / 报错原文**。

```
我在做第 3 步，跑 go run main.go 报错：
undefined: fmt
我试过加 import "fmt"，还是报同样的错
```

只说「不行了」「跑不起来」，他只能瞎猜，你会更晕。

---

## 三、第四步「副本」：这才是真学东西的地方

1. 讲完一课，助教会**按你的进度**安排一个副本（不用你自己挑）
2. 他会建一个文件夹，里面有一个 `README.md`
   → 位置：`桌面\小穗\10-项目\voyage-练习\<项目名>\`
3. **README 就是你的任务书**：做完能得到什么 / 你要做的几步 / 验收标准
4. 你自己做，**别让助教写代码**（他要敢写，你就说「只告诉我下一步看哪块」）
5. 做完了，在副本里点「**提交，让助教检查**」
6. 助教会逐条跑验收，给你看：✓/✗ + 跑的命令 + 该看到什么 + 你的实际输出
7. **过关才算副本完成**；没过就留在这一关，改完再提交

### 没过会发生什么

没过的每一条会变成你的**弱项**：
- 下次讲课他会针对这些弱项
- 下一个副本也会优先补它们

所以没过不是失败，是**系统记住你卡在哪了**。

### 一条重要规则

**一次只有一个副本**。前一个没过，不会给你新的。
这是为了防止你「开了十个坑，一个都没填」。

---

## 四、第三步「复习」：别跳过

到期卡片会出现在左侧「到期复习」里。

- 点开 → **先凭记忆想一想**它讲了什么、能怎么用
- 然后诚实自评四档：忘了 / 想不起来 / 想起来 / 轻松
- 自评准，安排才准；想不起来就点回那节课重看

**别用「重读一遍」代替复习**。真正的检验是「不看资料，还能不能说/写出来」。

---

## 五、笔记（可选，但很有用）

- 把笔记放在程序的 `notes/` 文件夹里（Markdown 就行）
- 让助教巡检一次：他会对照你学到哪，逐篇指出**讲错的概念**、**漏掉的关键点**、**结构建议**
- 巡检结果会出现在界面上，不是悄悄吞掉

---

## 六、每天 30 分钟怎么用

```
5 分钟   看昨天的复习卡，答一遍（忘就忘，别翻资料）
15 分钟  今天这节：跟着做，走到「空白重写」
10 分钟  副本推进一小步（做不完就明天接着）
```

**不要**一次坐三小时。学得进去靠的是**每天一次、每次到「自己写出来」**。

---

## 七、别做的事

| 别做 | 为什么 |
|---|---|
| 让助教直接把答案/代码写出来 | 那样你只会「看着懂」，第二天全忘 |
| 跳过「空白重写关」 | 这一关就是用来戳破「我好像会了」的错觉的 |
| 同时开好几个副本 | 一个都没填完时，前面学的会先忘了 |
| 只看不算 | 每一关的结果都要能贴出来（输出、截图、代码） |
| 装懂 | 探底那一句答「会」，后面就会讲快，你会更晕 |

---

## 八、什么时候算「学到东西了」

不看学了几节、看了多少页。看三个：

1. **闭卷能复现**：清单上那几条，不看资料能不能写出来/说出来
2. **换场景能用**：换个需求，还会不会用同一套东西
3. **隔几天还在**：一周后再问，还记得多少

这三个都过了，才算真的会。分数、时长、完成率都不算。
