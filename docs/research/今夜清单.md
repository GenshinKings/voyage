## 1. NOAA 深海生物光的三种作用（我自己一直没办成的事）

之前直抓 NOAA 的 PDF 是乱码，讲不成。这次让 ZCode 从 HTML 原典里读出来，三种作用各有原理、代表生物、出处：

- **反向照明（counterillumination）**：发光器长在腹面，朝下发与上方环境光同等强度的光，从下面仰视时剪影被自己的「底灯」抹掉。代表：眼闪鱿鱼 *Abralia veranyi*。
- **遇险发光（burglar alarm）**：被咬住时爆闪，不是求饶，是把更大的捕食者引来攻击捕食者。Widder 的原话是「用光喊救命」。代表：深海洋冠水母 *Atolla wyvillei* 的旋转光轮。
- **诱饵（lures）**：头前晃动的发光杆，把猎物引到嘴边。代表：杆首龙鱼 *Eustomias pacificus*。

还挖到一条我没想到的：Widder 用 16 颗蓝 LED 模仿 Atolla 的警报光，装在红光照明（深海动物看不见红光）的相机上，靠这套「假水母」拍到了**大王乌贼的第一段原位视频**。

## 2. Ozon 跨境卖家要点（直接关系到他能不能出单）

- **鉴权现状**：仍是 `https://api-seller.ozon.ru` + `Client-Id` / `Api-Key` 双 header；另有一条 OAuth「私人应用」通道，面向对外发布的第三方应用。
- **code 7 = gRPC PERMISSION_DENIED**，不是 Ozon 私有码。四个常见原因（按命中率）：密钥被重置/权限不足 → 账号被封连带 API 停用 → **中国大陆出口 IP 触发风控** → 调用已下线的方法。
- **官方解法路径**：重生成密钥 → 核对角色权限 → 仍失败就邮件 `dev@ozon.ru`，附 Client-Id、完整响应体、请求时间、出口 IP。
- **秋冬品类公开数据**（Ozon 官方披露经媒体转述）：9 月轮胎需求 1.69×、10 月 2.11×；家用红外桑拿 4.2×；腌渍容器 3.1×、真空包装机 2.1×；**冰爪防滑鞋套 18.8×**；新年摆件购买频次 9×。

这条对我之前的判断是个修正：我只说了「账号级被禁」，漏了 **IP 风控** 和 **旧方法下线** 这两种可能，也漏了可以直接写信给 `dev@ozon.ru` 这条最省事的路。

文件：`docs/research/Ozon-跨境卖家要点.md`

## 3. Agent 可靠性与记忆（怎么让我自己更靠谱）

十篇论文/工程博客收敛成 10 条规则，其中最扎心的三条：

- **验证不足是多 agent 失败的最大类之一**（MAST，21–31%）——「执行完毕」和「验证完毕」必须是两个动作，写操作要做回读。
- **同参重试是典型失败模式**：每次重试重新采样出几乎相同的参数，同样的错连吃 N 遍。要按工具名+参数指纹硬阻断。
- **「我不知道」要能被说出口**：评测里「自信答错」罚得必须比「弃答」重，否则编造就是理性选择。

我自己先认的三条：写后回读、同参重试阻断、证据与推断分离。

文件：`docs/research/Agent可靠性与记忆.md`
