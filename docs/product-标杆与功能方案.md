# 下一代教育产品：标杆与功能方案

> 2026-10-31 · 讨论产出（主人 + 小穗）· 与 `PLAN-voyage-3.0.md` 配套：
> 3.0 讲「怎么从学会转向交付」，本文讲「凭什么说这产品是好的，以及具体做成什么样」。

## 一、标杆：什么才算「好」

**不是「教得更好」，是「能证明人变了」。** 判据从「学完了」换成「交付物可验证」。

「合格」判三样东西——**不是判人，人只累积证据，不打分**：

| 判什么 | 具体问题 | 谁判 |
|---|---|---|
| ① 产物 | 按它自己声明的验收标准，能不能用 | 机器（跑得动就是跑得动） |
| ② **你的判断** | 你说「这里不确定」，事后真有毛病吗？说「没问题」，真没问题吗？ | 人（事后对账） |
| ③ 过程 | 写成清单，下次照着还能过吗 | 自评 + 抽查 |

②是整套系统的灵魂，也是「验收能力」的度量。市面上几乎没有产品在度这个。

## 二、两个否定性结论（比正面清单更重要）

1. **个性化不是换语气**。它是**错误模型**：知道你会栽在哪、为什么栽、下次怎么不栽。
2. **陪伴不是教育目标**。「AI 助教陪着你」很容易变成粘性陷阱；陪伴是留存手段。
   好东西应该让人**更快毕业**——这和所有教育产品的商业逻辑是反的，必须正面承认这个矛盾。

## 三、护城河：行为轨迹

不是题库，是这三类只在真实使用中产生的东西：

- **错误谱系**：概念 / 条件 / 环境 / 粗心 —— 你反复栽在哪一类
- **动机结构**：你为什么想做（自主 / 胜任 / 归属），靠行为反推，不靠问卷
- **工作方式**：你习惯先看文档还是先动手；卡住时先搜还是先问人

抄不走，也没法用公开数据训练出来。

## 四、「喜欢」怎么测（原问题：算不出来）

**结论：产品不该去算「你喜欢什么」。** 时间 × 学习情况那个四象限永远算不出来，
因为这两个是**果**不是**因**，样本一变结论就翻。

产品只做两件事：**给可选样本** + **记录你选了哪个**。目标改成：

> 让你在三次尝试内**暴露**偏好。

能落进产品的偏好证据只有三样：

1. **超出验收要求自己多做的**（验收只要求跑通，你顺手加了帮助信息）
2. **回头偷偷改的**（过了关又回去调结构）
3. **拒绝让 AI 代劳的**（宁愿自己写也不让 AI 代做）

## 五、功能：五块

| # | 模块 | 做什么 | 现状 |
|---|---|---|---|
| 1 | **麻烦收件箱** | 一句话记下今天的真麻烦，一键变任务 | 缺 |
| 2 | **任务卡** | 目标 / 验收标准 / 参考但不给答案 / 30 分钟内能做完 | 有雏形（run templates） |
| 3 | **验收台** | 机器查能不能跑；**你补一句「我哪里还不确定」** | 有雏形（judge + 待判队列） |
| 4 | **复盘卡** | 卡点四分类 + 一句「下次怎么办」→ 进错误谱系 → 决定下一题 | 有雏形（stats + causes） |
| 5 | **履历导出** | 交付物 + 你当时的判断 → 能给雇主看 | 缺 |

**明确不做**：课程树、知识图谱、聊天陪伴、排行榜。四样都好看，都不产生交付。

## 六、判定的放权节奏

- **前 5 次**：你来判（校准期）——让系统学会你的标准
- **之后**：机器判，你抽查；抽查发现判错，就记一次「判定偏差」，反过来校准
- 这一条决定了评测集从哪来：**你的前 5 次判定就是评测集**

## 七、阶段计划

| 阶段 | 做什么 | 验收 |
|---|---|---|
| P1 | 麻烦收件箱 + 任务卡（把真实麻烦变成任务） | 能从一个麻烦生成一张带验收标准的任务卡 |
| P2 | 验收台补「我不确定」这一栏 + 事后对账 | 每条不确定都能被标记「后来真出问题了吗」 |
| P3 | 复盘卡接错误谱系，按错误出下一题 | 同类错误 ≥2 次必须插针对题 |
| P4 | 履历导出（交付物 + 判断记录） | 导出一份陌生人能看懂的成果说明 |

## 八、风险（不粉饰）

1. **难度不可预期**：真实问题有时十分钟过关，有时三天。体验会比「一天一课」差。
2. **验收难标准化**：「别人照着能用」只能人判，规模化会卡在这里。
3. **不靠它赚钱 → 时间预算有限**：范围必须砍到「一个人一年能维护」，否则三个月烂尾。
4. **零基础用户**：第一关要拆到「装环境 → 跑到输出」，否则第一步就劝退。
5. **粘性诱惑**：只要开始做陪伴和排行榜，产品会更快变好看、更慢产生交付。

## 九、待定

- 开源贡献的「最小单位」还没定：给可跑的实验/插件，而不是让人提 issue。
- 第一条交付物选什么：建议从他自己的真麻烦里选（Ozon 选品、店铺诊断、笔记检查）。
