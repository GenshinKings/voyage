# 插件化的 voyage：把内核留在 Go，把入口放进对话

来源：2026-10-28 23:30 主人提出「直接做成 harness 插件，装上后就能按插件规则定制学习内容」。
本轮只出设计，不改 voyage 内核、不写代码。

---

## 一、先说清楚边界（为什么不全搬进插件）

| 想搬的 | 能不能搬 | 原因 |
|---|---|---|
| 教学逻辑、判定、归因、FSRS 复习 | ✗ 不搬 | 这些是产品命门，且已有 18 个包的测试护着 |
| 学习数据（履历、笔记、状态） | ✗ 不搬 | 数据在本地 `outpost2-data/`，换宿主就该还在 |
| 三步卡、时间档、知识地图 | ✗ 不搬 | 聊天窗口做不出这些界面；硬做会退化成一堆文字 |
| 「今天学什么 / 交作业 / 看履历」这三个动作 | ✓ 搬 | 这三个动作本来就不需要界面 |

**结论**：插件是**入口**，不是替身。用户在对话里说一句话就能推动学习，想看界面时点链接回到网页。

## 二、插件形态

- 包名：`dsh-voyage`
- 类型：DSH bundle 插件（`cordis.patch.yml` + `lib/index.js`），与 `dsh-bili-whale` 同一种装法
- 安装：`dsh plugin --profile web add "link:<插件目录>"`，重启生效
- 配置项（`~/.dsh/voyage.config.json`）：
  - `baseUrl`：默认 `http://127.0.0.1:7412`
  - `autoStart`：默认 `false`（是否在工具被调用且服务没起时尝试拉起 `voyage.exe`）

## 三、四个工具

| 工具 | 调用 | 行为 | 失败时 |
|---|---|---|---|
| `voyage_today` | `GET /api/state` | 返回今天的课（标题/简述）、三步进度、当前时间档；若今天还没开课，先 `POST /api/tutor/open` 拿开场 | 服务没起 → 返回「学习服务没开」，附启动方法 |
| `voyage_submit` | `POST /api/tutor/send` | 把用户这段回答交给助教，返回助教回复 + 判定（pass/partial/fail）+ 引导档位 | 同上；`nodeId` 缺失时先用 `voyage_today` 里的 id |
| `voyage_resume` | `GET /api/state` 的 counts + `POST /api/resume/doc` | 返回「已学会 N 个 / 用过 M / 当前卡在哪个知识点」 | 同上 |
| `voyage_open` | 无 | 返回一次性链接 `http://127.0.0.1:7412/?v=<ts>`，供 GUI 打开完整界面 | — |

**共同要求**：
- 所有工具都只读本机 `127.0.0.1`，不接收外部 URL（防 SSRF）
- 单次调用超时 10s，超时返回可读提示而不是抛栈
- 返回值里不放盘符路径、不放 token

## 四、对话里的样子（验收用例）

1. 用户：「今天学什么」
   → 工具返回：今天的课 + 三步 + 一句「先说你打算怎么开始？」
2. 用户贴一段自己的答案
   → `voyage_submit` 返回助教点评 + 是否通过；通过则提醒「去把练习做掉」
3. 用户：「我学过什么」
   → `voyage_resume` 返回已学会清单 + 一句「上次你卡在 X」
4. 服务没起时问「今天学什么」
   → 「学习服务没起，双击桌面那个启动脚本就能开」——**不许沉默、不许报错栈**

## 五、验收（缺一不算完成）

- [ ] 装好后在 DSH 对话里说「今天学什么」，能拿到真实的今日课程（不是硬编码）
- [ ] 交一次作业，返回的判定与网页端一致（同一 `nodeId` 对比两次结果）
- [ ] `voyage.exe` 停掉时，三个工具都返回人话提示，进程无异常退出
- [ ] 工具清单里能看到这四个，且名称前缀统一为 `voyage_`
- [ ] `grep -r "C:\\" 插件目录` 为 0（不含配置示例里的占位）

## 六、明确不做

- 不复刻三步卡/地图/时间档的界面
- 不做多用户、不做云同步
- 不在插件里写学习数据（一律走 Go 服务的 API）
- 不替用户决定学什么（选课逻辑仍在内核）

## 七、风险与代价

| 风险 | 说明 | 缓解 |
|---|---|---|
| 宿主升级改插件 API | 插件是客人，宿主换衣就得跟着改 | 插件只依赖 HTTP + 最少宿主接口；内核不动 |
| 用户只装插件不装内核 | 插件没内核就是空壳 | 安装说明第一步写明「先跑起 voyage 服务」 |
| 两套入口认知分裂 | 有人只在对话用，有人只用网页 | 数据同源；网页里也提供「在对话里继续」的入口 |
