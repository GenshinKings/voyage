# 第九轮：把「不好用」的部分一次做完

来源：2026-10-28 22:46 主人要求「检查还有哪些功能做得不太好，一次性提交给 ZCode」。
筛选标准：只收**有具体证据、能写验收**的项；大件（多用户/云同步）不进本轮。

## P0-1 用户看到的错误文案要像人话，技术细节只进日志

**证据**（源码里直接返回给前端的字符串）：
- `internal/llm/exercise.go:68` → `LLM 未配置（outpost2-data/llm.json）`
- `internal/llm/exercise.go:89` → `出题解析失败：%s`（%s 是原始报错）
- `internal/ghfetch/ghfetch.go:80` → `GitHub 返回 HTTP %d`
- `internal/ghfetch/ghfetch.go:152` → `…页面结构可能变了（HTTP %d，前 200 字节：%s）`

孩子看到「outpost2-data/llm.json」只会更慌，也不会因此修好任何东西。

**要做**：错误分两层
1. `UserMsg`（短、人话、带下一步）：「今天的出题还没接上模型，去设置里贴一个就能用」
2. `Detail`（原始错误、路径、HTTP 码、响应片段）只写日志 + 存 `/api/diagnostics`，**不返回给前端**

**验收**：
- 未配置 LLM 时调 `/api/exercise/generate`，响应体里不含 `llm.json`、不含盘符路径、不含 `HTTP`
- 同一时刻日志里能查到完整技术细节
- 新增单测：断言上述四个调用点的用户文案不含 `.json`、`http`、`C:\`、`/home/`

## P0-2 三个空态页要能继续走，不能是死胡同

**证据**：干净的本地数据下，「练习」「沉淀（学会的）」「知识地图」三个视图几乎空白（今天重拍 README 截图时暴露，只能拍成空态）。

**要做**：每个空态给「为什么空 + 一个主按钮」
- 练习空：说明「练习要等今天这节收尾后生成」+ 按钮「回到今天的课」
- 沉淀空：说明「答对并通过点亮的才会出现在这里」+ 按钮「去答一题」
- 知识地图空：说明「关联图只画你真实调用过的知识点」+ 按钮「去练习一次」

**验收**：清空数据启动，三个视图各自都有 ≥1 个可点主按钮，点下去能到正确视图（用 handler 测试断言跳转目标，不用截图比对）。

## P1-1 清死代码与遗物

**证据**：
- `internal/sandbox/library.go:65` 用 `appand(...)` 调用一个包装函数，紧跟着一行 `// TODO: 好像不太对？`——这个包装就是 `append` 的错拼，纯隧道
- 第八轮刚把 server.go 拆成五个文件，可能有没用上的字段/函数

**要做**：
1. 干掉 `appand` 包装与那行 TODO，直接 `append`
2. 全仓跑一次死代码扫描（`go vet` + `golangci-lint` 的 unused，或 `golang.org/x/tools/cmd/deadcode`），把确实没用的导出函数/字段删掉；删之前先 `grep` 确认无 `_test.go` 引用

**验收**：`deadcode ./...` 输出为空或只剩测试辅助；`go build`/`go test` 全绿；`appand` 全仓 0 命中。

## P1-2 键盘可用性最小集

**证据**：`index.html` 里 `aria-` 只出现 1 次，主要交互靠鼠标点击。

**要做**：
- 主按钮、输入框补 `aria-label`
- Tab 能顺序聚焦到「输入框 → 发送 → 今天三步」
- Esc 关闭任何弹层/卡片（现在只能点关闭按钮）

**验收**：只用键盘完成「打开 → 输入回答 → 发送 → 收尾」流程；`grep aria-` ≥ 10 处；Esc 关闭在单测里用 DOM 断言（或前端手测记录写进 commit message）。

## P1-3 窄屏不出横向滚动

**证据**：页面按 1500×1000 设计，只有 4 个 `@media`；README 截图就是 1500 宽。

**要做**：补 1100px 与 900px 两档，把侧栏收成可折叠、卡片改单列。

**验收**：1100 与 900 宽下 `document.scrollingElement.scrollWidth <= clientWidth`（Playwright 断言，写进 commit message）。

## P2-1 让「数据只在本机」看得见

**证据**：`/api/export/all` 存在，但界面里几乎找不到入口，也没一句话解释数据在哪。

**要做**：设置页加一块「你的数据」——一句「全部存在这台电脑上，不上传」，加一个「导出全部」按钮走 `/api/export/all`。

**验收**：设置页能看到该区块，点击后下载到文件；文案里不出现任何本地绝对路径。
