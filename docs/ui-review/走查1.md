## 仍然硌人的地方（≥3 条真实困难，留给下一轮）

### 1. 结构化判定有「多烧一次调用」的代价
标记缺失的每一轮都会触发一次独立判定调用。对话闲聊里助教偶尔反问「对吧？」也会命中判定器——判定器说 fail 就记一次误因。**现象**：闲聊轮可能被误记错因。**建议**：给判定结果加置信度，或只对「含明确验收动作的检查题」触发。**状态**：待观察（需要真实使用数据说话）。

### 2. 「？？？是什么」的悬念摩擦
影子副本候选卡只给需求与难度，零基础孩子第一反应是想知道「我要做什么」。悬念是对的（揭晓时刻的价值已验证），但导读文案必须把「开门后大概做什么」讲透，否则他不敢开门。**状态**：导读模板待真实学生数据校准。

### 3. 记忆巩固一天只跑一次，白天的矛盾要等到夜里才被 UPDATE
早上说「在学 Python」、下午改口「改学 Go」，当天开场仍会引用旧记忆。**建议**：会话收尾时做一次轻量增量巩固（或引用时让助教先问一句「这个还作数吗」）。**状态**：待定——先看真实使用里矛盾出现的频率。

### 4. 第二天的续接还没验过
LastStop 接续锚、FSRS 到期卡、记忆引用三者在「第二天打开」时的合流体验没有走过完整走查（本次只有单日模拟）。**状态**：走查 2 的第一任务。

## 一句话结论

第五轮提的「闭环会静默断开」已经从机制上修掉（双通道 + 诊断 + 追问不丢）；现在最贵的风险从「断」变成了「慢半拍的记忆」和「没被真实孩子摸过的第二天」。
