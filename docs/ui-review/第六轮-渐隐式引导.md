# 第六轮：让助教变成「会渐隐的老师」

目标：助教从「老师讲、学生听」变成「引导式教学，但新手不被问懵」。同时开始积累学习者模型。

---

## 一、苏格拉底渐隐式引导（P0，核心）

### 设计
同一节课有三种引导模式，**随人切换，不随课程切换**：

| 模式 | 助教怎么说话 | 用给谁 |
|---|---|---|
| 样例模式 | 先给一个完整例子 + 直接指令：「照着这个改，把 X 换成 Y」 | 新手 / 刚卡过 |
| 半提示模式 | 给方向不给答案：「你要找的东西在 A 里，想想它对 B 做了什么」 | 中间态 |
| 提问模式（苏格拉底） | 只提问：「你觉得这行执行完，变量还是原来的值吗？」 | 熟练 / 连续通过 |

### 切换判据（写死，可审计）
- 连续 **3 次**判定通过 → 上移一级（样例 → 半提示 → 提问）
- 连续 **2 次**未通过 / 点了「我卡住了」→ 退回一级
- 每节课开始用上节课结束时的档位；首次接触新知识点默认样例模式

### 验收
- 同一节课连对三次后，助教的下一句话必须是提问形式（不出现「你应该……」的直接指令）
- 连错两次后，下一句必须含完整样例
- `/api/state` 里能读出当前档位（`guideLevel`）

---

## 二、误因分类（P0，学习者模型起点）

判定失败时，让判定的 LLM 同时输出一个归因标签：

```json
{ "verdict": "fail", "reason": "concept|condition|env|slip", "evidence": "他写的 a==b 应该是 a!=b" }
```

- `concept` 概念没懂
- `condition` 看漏条件
- `env` 环境/报错相关
- `slip` 手滑/拼写

存进 `stats.wrongReasons[lessonID] = {concept: n, condition: n, ...}`。

**用途**：下次讲同一知识点时，助教开场先说「上次你这里是想反了」，而不是重头讲一遍。

### 验收
- 连续答错两次后，state 里能看到该知识点的原因分布
- 第三次讲同一知识点时，开场第一句必须引用上次的原因

## 三、追问判「真会」（P1）

判定通过后，加一次追问：
> 「你为什么会这么写？一句话。」

- 答得上 → 收尾（履历 +1）
- 答不上/含糊 → 记「半懂」，不推进，给一个更小的同类题

**防滥用**：追问只对「首次通过」触发，重复通过不再问。

### 验收
- 首次通过必然出现追问
- 追问答不出时，履历不加、且生成一道更小的题

---

## 四、用他自己的仓库出题（P1）

沙箱已能读文件。出题时优先取材于学习者的真实代码：

- 选题时从 `sandbox` 读到用户最近改过的文件（或仓里任意 `.go`）
- 题目形式：「这段函数在什么输入下会返回错的值？」「这行能不能删？为什么？」
- 若读不到文件，退回通用例子

### 验收
- 有可用文件时，题面出现真实文件名与真实函数名
- 无文件时，自动退回，不报错

---

## 五、给前端的两处小改

1. 今天三步的「讲」卡上显示当前引导档位：`样例` / `半提示` / `提问`（小字，不喧哗）
2. 卡住时显示「已退回一档」的轻提示（一句话，不弹窗）

---

## 六、纪律

- 不改变「收尾是唯一里程碑」这条宪法
- 所有切换判据写成常量并注释来源（为什么是 3 和 2）
- 每项单独 commit，并在 commit message 标注 第六轮-P0-x / P1-x
