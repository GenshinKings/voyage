# 第五轮追加：深色主题（2026-10-27 20:52）

用户反馈：深色模式下「啥也看不清」。

## 现状（代码事实）
- `index.html` L409 仍是 `@media (prefers-color-scheme:dark)` 自动切深色；
- 也就是说：用户的 Windows 是深色模式，应用就被动变深，而这套深色没有被逐页验证过对比度。

## 要做的事

1. **默认锁浅色**：删掉 `@media (prefers-color-scheme:dark)` 自动生效这一段，改成只有 `[data-theme=dark]` 才生效。
2. **设置里加开关**：`外观：浅色 / 深色（测试中）`，存 `localStorage['voyage.theme']`，启动时应用；不跟随系统。
3. **深色下逐页过对比度**：正文与背景 ≥ 4.5:1，次要文字（`.mut`）≥ 3:1。至少覆盖：今天、对话气泡、练习卡、副本、沉淀、知识地图、设置弹窗。
4. **关联图颜色走变量**：画布里的节点、连线、文字、高亮全部改成读 CSS 变量（`getComputedStyle(document.documentElement).getPropertyValue('--ink')` 等），切主题时重绘。
5. 验收：深色下截图 5 张，每张能看清正文；浅色是默认。

单独 commit。
