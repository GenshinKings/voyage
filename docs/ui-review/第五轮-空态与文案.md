## 一、空态（P0，真问题）

实测：点侧栏「知识地图」→ 画布整片空白、无任何文字；「学会的」（沉淀）同样空白。

下面一个按钮：`去完成今天的第一步` → `todayGoLearn()`。

同时：**图例始终显示**（现在空图时图例也看不到），让人知道这块是干什么的。

### 2. 沉淀空态
`renderSediment` 无数据时显示：
> ✓ 还没有已学会的知识点
> 助教判定「收尾」后，这里会按「知道 / 用过 / 做过」三个深度记录下来。

按钮：`继续今天的学习`。

## 二、文案（P1）

更正一下我之前的误读：输入栏按钮实际是「我会 / 深 / 我卡住了 / 🧪 / 发送」，不是「看 / 换」。其中：

1. **「深」→「再深一点」**：单字太难懂，tooltip 只有 hover 才看到。
2. **「🧪」→ 加文字「沙箱」**：图标无文字，新用户不会点。
3. **时间档说明**：`照实说就行——今天的量跟着你走` 这句可以删，四个选项本身已经表达清楚。
4. 「我会」保留，但 tooltip 改成更直白的：`这个我会——出一道验收题，过了就跳过`。
