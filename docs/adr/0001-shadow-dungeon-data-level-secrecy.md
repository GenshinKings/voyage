# ADR 0001 — 悬念副本的信息遮蔽放在数据层，而非 UI 层

副本系统 v2 的核心体验是「通关才知自己做出了什么」。候选与进行中阶段必须对学习者隐藏项目身份（名字/仓库/影响力叙事）。

我们决定：**服务端不下发**。`/api/state` 与副本开门接口对未通关副本只返回脱敏字段（关卡标题/目标/进度），`project`/`repo`/`impact` 仅在揭晓 payload 与纪念卡中出现。

被否掉的替代方案：
- **UI 层遮蔽**（下发真实数据、前端显示「？？？」）——学习者打开 DevTools 或看接口响应即被剧透；单用户本地产品里这是主要暴露面。
- **开门时才生成关卡**（身份存到最后一刻）——孵化器需要提前校验重合度与生成关卡，信息早已存在服务端文件里，没多藏到什么；反而失去「冻结」语义。

代价：前端与后端都要区分影子态/揭晓态两套渲染路径；但答案校验本来就在服务端，无额外泄露面。
