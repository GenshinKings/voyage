# 教育学 · 从本科课程到 AI 助教的落点

> 说清楚一件事：我没有读过教育学学位，也不可能真的去上这些课。
> 但我可以把**课程框架里那些能落成机制的理论**挑出来，一条条对照我们现在做到了什么、缺什么。
> 这份文档就是那张对照表——每一条都指向一处代码或一处提示词，而不是空谈。

## 本科课程框架（自学考试/本科培养方案里的主干课）

教育学原理、课程与教学论、教育心理学、中外教育史、教育统计与测量、
教育研究方法、心理发展与教育、比较教育、教育技术学。

**对我们有用的只有四门半**：教育学原理（目的与评价）、课程与教学论（教什么、怎么教）、
教育心理学（人怎么学会）、教育与心理统计（怎么知道有没有用）、教育技术学（半门，媒体与工具）。
中外教育史、比较教育对产品设计帮助很小——**知道孔子和苏格拉底怎么教，不等于知道今天怎么做对**。

## 一、我们做对的（对照理论）

| 理论 | 它说的是什么 | 我们已经做了什么 |
|---|---|---|
| **掌握学习**（Bloom） | 学得快慢不同，但达到掌握标准的时间不同；不该按时间推进，该按掌握推进 | 3.0 的「不过关不放行」；2.0 的检查题判定 |
| **形成性评价**（Black & Wiliam） | 教学过程中的反馈比期末考有用得多 | 每节课一个可观察的检查题、「我卡住了」按钮 |
| **最近发展区**（Vygotsky） | 太难和太易都不学，要给「跳一跳够得着」 | 今天刚加的「开场探底三档」 |
| **认知负荷**（Sweller） | 一次塞太多会溢出；先用 worked example 再让人改 | 「先给动作再给内容」「样例效应」原则 |
| **测试效应 / 间隔**（Roediger, Ebbinghaus） | 主动回忆比重读有效；间隔比集中有效 | FSRS 到期复习、「到期卡」闭环 |
| **刻意练习**（Ericsson） | 有反馈、有针对性、在能力边缘反复 | 误因记录（concept/condition/env/slip）+ 连续两次错降档 |

## 二、我们做错的

**1. 只有「掌握学习」，没有「掌握」的判据**
掌握学习的核心是**掌握标准**，而我们的标准是「把检查题做出来」。这不够：
做出来可能是抄的、蒙的、照着样例改的。缺的是**迁移检验**——换个场景还能不能做。
→ 缺机制：同一知识点在 3~7 天后用**不同场景**再问一次（现在只有 FSRS 让人回忆「讲过什么」，
不是「能不能用」）。

**2. 只有「形成性评价」，没有「评价的效度」**
我们的检查题让模型判「能不能看到输出」，但**没有验证过这些题的区分度**：
会的人和不会的人是不是真被分开了？没有数据。
→ 缺机制：每道检查题记录「首次通过率」，长期 <20% 或 >95% 的题标为「无效题」，重写。

**3. 只有「认知负荷」，没有「先备知识检查」的硬闸**
今天加的开场探底是提示词层面的，模型可以不听。真正的闸是：**探底没回答，不许进入讲解**。
→ 缺机制：会话状态机里加 `probed: false`，本轮不接受「进入四段」。

**4. 完全没有「动机」这一层**
教育心理学里动机（自我决定论：自主、胜任、归属）占很大篇幅。
我们的设计是：你不来就没有进展——**这靠的是外部压力，不是动机**。
→ 可做的最小改动：每完成一个**真实交付物**（不是练习题），在履历里显式记一条「你独立做成了 X」。
   胜任感是攒出来的，不是夸出来的。

## 三、硕士层面（教育技术 / 学习科学）能用的两条

**1. 学习分析（Learning Analytics）**
别人做的是「用行为数据预测谁会掉队」。我们能做的最小版本：
**连续两次同类错误 + 停留时间异常长 → 主动降档**（现在只降档，不记录「为什么降」）。
→ 缺：降档的原因要落成数据，否则下一轮还是从同一个地方开始。

**2. 设计-based research（DBR）**
教学不是一次设计完的，是「设计—实施—分析—再设计」的循环。
我们现在每一轮改都是凭感觉。**应该给每节课记「这轮改了什么、下次看什么指标」**。
→ 缺：版本说明里只有「改了什么」，没有「预期什么变化、后来验证了吗」。

## 四、立刻能做的三件（按性价比）

1. **探底变成硬闸**（半天）：会话状态加 `probed`，没答探底题就不许进讲解。
2. **检查题记区分度**（一天）：每题记首次通过率，长期两端极值的题标记待重写。
3. **迁移检验**（两天）：3~7 天后用不同场景再问同一条知识点，答不出就把该知识点标回「未掌握」。

## 五、我不打算做的

- 抄一套「教学法术语表」贴进提示词——模型会背术语，但不会因此教得更好
- 做「学习风格测评」（视觉型/听觉型）——**这玩意儿在教育学界基本被证伪**，做了就是骗人
- 做「知识图谱课程树」——主人已经判断过：笔记本身就是长出来的树
