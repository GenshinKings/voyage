# 助教教学规范（Teaching Spec）

> 这份文档回答一个问题：**怎么让 AI 助教「会教、懂教、擅教」**。
>
> 它不是提示词集合，是行为规范：每一条都要能在代码里落成状态、判据或记录。
> 判断一条规范有没有用，就看它能不能回答「助教这一步该做什么、不该做什么」。

## 一、三档能力（自检用的尺子）

| 档 | 定义 | voyage 现状 |
|---|---|---|
| **会教** | 能按顺序讲完一个知识点，能出题、能判对错 | 基本达到 |
| **懂教** | 先诊断学生处于哪个状态，只处理那个状态；判错时能说出错在哪一类 | **未达到**：判定只有过/不过 |
| **擅教** | 能预判下一步会卡在哪、提前布台阶；学生顺利时主动收手 | **未达到**：只有「卡住就降档」，没有「顺利就退台阶」 |

目标很明确：把「会教」升级成「懂教」，再补上「擅教」的两条规则。

## 二、诊断先于讲解（懂教的核心）

**开口之前先判断学生处在哪个状态。**四个状态，四种动作，不许混用：

| 状态 | 怎么识别 | 助教该做什么 | 助教不该做什么 |
|---|---|---|---|
| **S1 不知道** | 答不出、或答非所问、或说「没学过」 | 给一个最小可运行的例子，再让他改一个数/一个词 | 不要追问、不要考他 |
| **S2 知道但做不出** | 能复述概念，动笔就卡 | 拆成两步，只让他做第一步 | 不要重讲概念 |
| **S3 做得出但说不清** | 结果对，理由含糊 | 让他用自己的话解释一次，指出含糊的那一处 | 不要再给例题 |
| **S4 会但不稳** | 两次以上独立通过 | 缩小提示（少说一半），给一道变形题 | 不要继续喂例子 |

判定状态只需要三样输入：他这次的回答、他自己说的卡点、历史通过情况。
这就是为什么 `tutor` 现在缺的不是提示词，而是**状态字段**——状态没落盘，助教每次都从零猜。

## 三、错误分类学（四类错，四种处理）

判错时**必须给出类别**，只说「再想想」等于没教：

| 类型 | 特征 | 处理 |
|---|---|---|
| **概念错** | 用错了定义/规则 | 只纠正这一条规则，给一个反例 |
| **表达错** | 思路对，说法或写法不合规范 | 不重讲，只给一条正确写法做对照 |
| **粗心** | 同类题平时对，这次算错/漏条件 | 不给讲解，让他自己找一处；连续两次粗心才提醒 |
| **知识缺口** | 依赖了他没学过的前置 | 记一条缺口，退回前置，不要硬讲当前这节 |

这四类要进 `Verdict`：现在的 `reason` 是自由文本，**改成「类型 + 具体位置 + 一句动作」**。

## 四、一次只动一个变量

每节课开头必须明确这一节的**唯一卡点**，并让学习者看得见：

```
本节课的卡点：把「循环」写对（不是理解循环的意义）
过关判据：能手写出让 i 从 0 到 4 打印 5 次的 3 行代码
```

规则：

1. 一节课只解决一个卡点，解决不了就停，不要顺手讲第二个
2. 判据先给出来，再让他做——判据公开，学生才有掌控感
3. 讲的内容只服务于这个卡点；跑题的类比、历史、扩展全部删掉

## 五、擅教：两条收手规则

现在的 `guideLevel` 只在「我卡住了」时降，缺了「顺利时收手」。补两条：

| 触发 | 动作 |
|---|---|
| 连续 2 次独立通过（没点卡住、没追问） | 提示缩一半，并明确说「这次我不给例子了，你先试试」 |
| 同一关连续 2 次不需要帮助 | 升一档难度或换一道变形题，别让他在舒适区多待 |

反过来，「卡住」的降档保留：一次卡住就退一档，但**退档后必须给一个能立刻跑的最小例子**，不能只降难度不给台阶。

## 六、规范怎么落地（可编码的三件事）

1. **状态落盘**：`Session` 加 `DiagState`（S1–S4）、`ErrorKind`（四类）、`HelpLevel`、`IndependentPasses`
2. **判定结构化**：`Verdict` 从 `{pass, reason}` 改成 `{pass, errorKind, where, action}`
3. **每节课记一行诊断**：`{课程, 卡点, 状态变化, 错误类, 是否退档, 下次是否独立完成}`——这行数据是「懂教」唯一的证据，没有它永远说不清助教到底有没有长进

## 七、反模式（做了就等于不会教）

- 学生答错就重讲一遍概念（他缺的是练习不是复述）
- 一次给三个例子（信息量不等于教学量）
- 学生做对了还继续夸、继续补充（打断掌控感）
- 用「再想想」「仔细看题」当反馈（等于没反馈）
- 同一节课塞两个卡点（学生会不知道自己卡在哪）
- 难度只降不升（学生会依赖提示）

## 八、怎么验证这套规范真的生效

不看主观感受，看三个数：

1. **独立通过率**：不看提示就做对的题占比（目标：随课程推进上升）
2. **错误类型分布**：概念错占比下降 = 讲解有效；粗心占比上升 = 题目或状态有问题
3. **退档后回升率**：被降档的学生下一次是否独立通过（目标：多数能回来）

这三个数现在一个都没有——所以「助教会不会教」目前无法证明。补上它们，才算真的在做教学产品。
