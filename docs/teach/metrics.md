# 教学指标：公式与口径

> 定这条的原因：比率是最容易被滥用的东西。1 次判定里的「100% 通过率」和 100 次判定
> 里的 100% 完全不是一回事。所以这里规定三件事：平滑、样本门槛、趋势只做差不下结论。

## 一、平滑后的独立通过率

```
平滑率 = (independent + 1) / (judged + 2)
```

- `independent`：没点「我卡住了」、直接通过的次数
- `judged`：走过判定的总轮次
- `+1 / +2` 是拉普拉斯平滑：避免 1/1 显示成 100%，也避免 0/0 变成 NaN

**为什么不直接用 independent / judged**：小样本时它的方差大到没有意义，
显示出来只会让人误判「我学得很好」。

## 二、样本门槛

```
judged >= 5 才显示比率
```

不足 5 次时界面显示「样本不足」，不显示百分比。
3 次判定算出来的比率是噪音，展示它等于误导。

## 三、两个聚合维度

| 维度 | key | 用途 |
|---|---|---|
| 按节 | 知识点 ID | 看哪一节课特别难（该补讲或该降难度） |
| 按天 | `YYYY-MM-DD` | 看趋势、看连续学习的质量变化 |

两者都存**计数**（judged / passed / independent / causes / downgrades / recovered），
不存比率——比率是读数时算的，不是存的时候算的。存比率会让「平滑」变成一次性决定，
以后想换公式就全废了。

## 四、趋势

```
前窗 = 距今 6~3 天     后窗 = 距今 0~2 天
趋势 = 后窗平滑率 − 前窗平滑率
```

规则：

- **两窗都要过样本门槛**，否则不显示趋势
- 只显示差值和两边的判定次数，**不显示「变好/变坏」的结论**——3 天窗口的噪音足够大，
  下结论就是把噪音当信号

## 五、错误类型分布

`concept / condition / env / slip / unfinished` 各自出现次数：

- **概念错占比下降** = 讲解有效
- **粗心（slip）占比上升** = 状态问题，不是知识问题（该休息、该减量）
- **env 占比高** = 环境阻塞，应该先修环境再教学，否则一直在教空气
