# Voyage 2.0 偏离审查（2026-11-03 22:45）

> 起因：主人问「对比最初的需求，看看 voyage 有没有做偏」。
> 基准两份：`docs/CONSTITUTION.md`（产品宪法，2026-10-14）与最初那句需求——
> 「让普通人成为未来 IT 公司需要的人才」，并修掉「必须我指导才能完成」「思维停在过去的教育方式」。

---

## 一、先说不偏的部分（三条，都是核心）

1. **确定性验收**：`/api/sandbox/verify`、`/api/reviews/verdict` 都在——判「做出来了没有」靠机器，不靠感觉。
2. **FSRS 排期**：31 处引用，间隔重复是真接上的，不是概念。
3. **把学习变成履历**：纪念卡、`/api/resume/*`、`/api/deliverables` ——「学完能证明」，正对最初那句「成为公司需要的人」。

这三条是原需求的主干，没走偏。

## 二、偏离一：北极星没被测量（最重）

宪法 1.1 写着目标函数是「**学会了，且想继续学**」，并给了四个度量：

| 度量 | 代码里的证据 |
|---|---|
| 确定性验收通过 | ✅ 有 |
| FSRS 延迟保持率（两周后再测） | ❌ 「保持率」0 处引用；排期有了，**结果没算** |
| 迁移（后续 break-fix 里直接可用） | ⚠️ 「迁移」14 处，多在提示词里，没有度量口径 |
| 自发回归 / 可选挑战 uptake / 会话末自报 | ❌ 「自发回归」0 处、「uptake」0 处 |

**结论**：产品能跑、能验收、能出纪念卡，但**回答不了「它到底让人学会了吗」**。
这恰恰是宪法说的「效果验证即产品」——现在验证环节是空的。

## 三、偏离二：接口铺到 81 个，违背「不堆功能」

`internal/server` 里挂了 **81 个接口**，横跨十六条线：agents / backlog / budget / inbox /
inkpal / notes / resume / trophy / sandbox / dungeon / exercise / direction / mood / fetch / graph / stats。

宪法开篇那句是：「此后每一波迭代都是在实现本宪法，而不是堆功能。」
现实是：**每个方向都做了一半，没有一条被用到能提结论的程度。**

判断依据不是接口数量本身，而是：主人今晚实测到第二课，被一个术语砸懵——
说明主干（课程难度梯度）还没打磨，边上已经长出十六条分支。

## 四、偏离三：难度梯度没有闸门

今晚实测：**第二课就出现「状态机」**，学习者当场懵。
原因不是内容错，是**没有地方检查「这节课会不会超出他的先验知识」**。
目前已补两条规则（术语后置、必须掌握清单），但**序列级检查还没有**：
谁来判断「这一课对现在的他太难」？现在没人。

## 五、偏离四：「AI 主导」做对了方向，但顺序错了

宪法 1.3 的操作原则是「AI 主动发起、learner 只学答判」——方向对。
错在**说话的先后**：先讲概念、再让他做；正确顺序是先让他做出东西、再给名字。
这条今晚已改进提示词，属于已修。

## 六、结论

| 维度 | 状态 |
|---|---|
| 验收 / 排期 / 履历 | ✅ 对 |
| 北极星度量 | ❌ 空 |
| 功能面 | ⚠️ 过宽 |
| 难度梯度 | ❌ 无闸门 |
| 术语与顺序 | ✅ 已修 |

**一句话：主干是对的，但它没有被测量，周边还长太宽。**

## 七、建议（按性价比）

1. **先做三信号的最小度量**（不新增页面）：
   - 保持率：复测到期时记一次「过没过」，按周算
   - 迁移：break-fix 里出现过复测卡对应知识的，记一次命中
   - 自发回归：不推送的情况下，距离上次会话 >24h 又自己打开，记一次
   三个数出来，才有资格谈「产品有没有用」。
2. **冻住十六条线**：除主干（讲→做题→副本→复测）外，其余入口先不投入。
   不是删，是加「实验」标记，明确「这条线没在验证」。
3. **加序列级难度闸门**：每节课开讲前，先按上一节清单和错题判断「这节会不会超纲」，
   超了就换一道更小的，或者先补地基。
4. ④ dungeon 闸门（复测未过不许进副本）留到度量有了再做——那本来就是它的数据来源。
