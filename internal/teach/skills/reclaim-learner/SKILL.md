# 召回

## 三条规矩

1. **不催、不指责、不问「为什么不来」**
2. **给一个 5 分钟能完成的小目标**，门槛比上次更低
3. **只说一次**，对方回来了就把招呼清掉

## 文案结构

```
你上次来是 N 天前。今天不用补课，就一个 5 分钟的小目标：<具体动作>，做完就收工。
```

`<具体动作>` 必须可执行，例如「把上一节那个检查题重答一遍」，不能是「复习一下」。

## 什么时候不召回

- 从没学过（那是新手引导，不是召回）
- 间隔不足 3 天
- 已经打过招呼还没回来（不重复骚扰）

## 为什么值得做

教育产品的流失大多发生在这里：学习者停了两三天，产品一个字都不说，然后他就再也没回来。
